# 使用与验收

## 按需参数

| 参数 | 规则 |
| --- | --- |
| `--dog-sequence 'dog_16,dog_37'` | 逐镜头编号，数量与有效镜头数相同，相邻编号不同。 |
| `--avoid-region X1 Y1 X2 Y2` | 可重复的避让矩形，满足 0≤X1<X2≤1、0≤Y1<Y2≤1；阻止交付时可放宽并记录。 |
| `--cuts '1.5,3.2'` | 视频切点秒数，各段至少 0.25 秒；空字符串表示单镜头，图片忽略。 |
| `--quality preview\|hd\|source` | 最长边分别限制为 1280、1920 或原尺寸；仅缩小，奇数宽高补齐为偶数。 |
| `--tracking auto\|flow\|off` | auto/flow 使用局部光流，off 为固定屏幕位置的顶层贴纸，忽略前景遮挡。 |
| `--allow-special-fallback` | 提前允许部分主体遮挡；默认先严格避让，必要时仍自动兜底。 |
| `--music 文件` | 仅用户明确要求替换音轨时使用；配乐提示不代表已添加歌曲。 |
| `--plan-only` | 只生成计划及跟踪预检，不生成视频，不得宣称已交付 MP4。 |
| `--image-duration 5` | 图片时长固定 5 秒，仅接受 5。 |
| `--timeout 秒数` | 单次媒体处理超时，默认 600，最小 1。 |

单批最多 64 个输入，共用禁区与切点；不同设置分别调用。人工场景计划每次只处理一个输入。

## 自动合成

选位最多采样三帧，合并人物、人脸、文字与显著区域提示。近处地面要求脚底到画面底部有宽通路、颜色与二维纹理证据。开阔草地独立检查连续面积、局部向下通路和纹理，允许底部前景截断草坪；优先右侧中部，但主体避让与动作边界优先。人工尺寸不自动放大超过请求值。

视频先低分辨率扫描分镜，再逐帧预检局部光流轨迹；每只自动狗最多同时尝试四个落点，共用解码。先寻找不低于 16% 的有效轨迹，再尝试小尺寸。开阔草地使用附近草地纹理跟踪，避免跟随底部前景。自动第二只狗没有独立角色或融合失败时省略；人工双狗采用一致层级。

自动前景使用相邻帧反向运动、当前颜色轮廓、GrabCut 与内置直立人物提示，减少人物离开后的残影。人工蒙版或轮廓关键帧优先。合成使用预乘 Alpha，遮挡同时衰减狗的颜色与透明度，并保留源画面。

弱纹理、遮挡、反射、形变、透视变化和密集行人可能导致漂移或轮廓误判。单镜头跟踪超过 18000 帧后使用贴纸；不支持通用三维重建。静态栏杆、细线、花束、树枝及移动载体需按实际画面指定承载区与遮挡。人工矩形不能证明已识别真实物体。

## 自动恢复

空间不足或轨迹不成立时整镜头使用顶层贴纸。选位、分析、场景配置、跟踪或融合异常触发一次独立恢复，采用至少一只可用狗、固定屏幕位置和直接 Alpha 合成。选中素材不可读取时换用其他随附素材；必要时移动人工落点或放宽禁区，完整动作始终在画面内。

优先保留第一条原音轨，复制失败转 AAC，两种方式均失败时允许交付无声 MP4 并说明。可读输入与可用素材必须得到真实结果；若输入不可解码、全部素材不可读、编码工具不可运行或输出目录不可写，先修复实际阻塞再执行。

## 结果检查

`summary.json` 给出实际输出与计划路径；逐文件 JSON 的 schema 为 4：

| 字段 | 含义 |
| --- | --- |
| `status` | `success` 对应实际已合成视频；`planned` 仅为计划。 |
| `shots[].dogs[]` | 完整小狗编号、相位、位置、承载区、遮挡及轨迹。 |
| `integration` | `static_surface`、`tracked_surface` 或 `top_layer_sticker`。 |
| `transforms` | 逐帧首帧到当前帧的显示像素 3×3 变换，静态或降级时为空。 |
| `fallback_reason` | 运动或遮挡降级原因。 |
| `scene_fallback_count` | 顶层贴纸镜头数量。 |
| `delivery_recovery` / `recovered_from` | 是否独立恢复及触发异常；普通贴纸降级不一定设置恢复字段。 |
| `placement.user_constraints_relaxed` | 交付时人工限制是否放宽。 |
| `placement_fallback_count` / `overlap_fallback_count` | 第一只狗备用选位与主体重叠数量。 |
| `music_suggestion` | 配乐提示，不代表歌曲已加入。 |

脚本检查尺寸、帧数、时长和音轨。视频转为 1–60fps CFR，VFR 逐帧 PTS 不保留，时长可相差约一个输出帧。交付前仍须查看实际 MP4，复核尺寸、完整动作、脚底滑动、主体抢占、轮廓误遮和多狗构图；跟踪预检通过不等于视觉效果正确。无需为普通处理运行开发回归或维护素材。

临时分析缓存与默认输出统一写入 `assets/temp_data/`。可在交付文件另存后删除该目录，不纳入 Skill 分发包。
