# 场景计划

仅在复杂承载面或遮挡需要人工指定时使用。为一个输入编写 JSON，`shots` 数量与有效镜头数一致；可用 `--cuts` 固定切点。图片只有一个镜头和一只狗，视频每镜头 1–2 只，受 `--max-dogs` 控制。

```bash
python3 scripts/render_overlay.py --inputs '/absolute/path/video.mp4' --cuts '' --scene-plan '/absolute/path/scene.json'
```

以下是单镜头承载区与移动前景示例，坐标须按实际画面填写：

```json
{
  "shots": [
    {
      "dogs": [
        {
          "id": "dog_16",
          "anchor": [0.35, 0.65],
          "height_ratio": 0.24,
          "support_region": [0.10, 0.65, 0.60, 0.90],
          "foreground": {
            "space": "screen",
            "keyframes": [
              {"time": 0, "polygon": [[0.1, 0.4], [0.14, 0.4], [0.14, 0.9], [0.1, 0.9]]},
              {"time": 1, "polygon": [[0.4, 0.4], [0.44, 0.4], [0.44, 0.9], [0.4, 0.9]]}
            ]
          }
        }
      ]
    }
  ]
}
```

- 坐标按转正后的显示宽高归一化到 0–1，不含补齐边缘。`anchor` 是首帧脚底；`height_ratio` 是完整动作画布高度比例，范围 0.04–0.60。编号与大小可省略，交由自动选择。场景计划不能与 `--dog-id`、`--dog-sequence`、`--anchor` 或 `--height-ratio` 同时使用。
- `support_region=[x1,y1,x2,y2]` 选择首帧中同一承载面的纹理区域。脚底横坐标在区内，纵坐标距上沿不超过 0.04；初始狗宽不超过该区宽的 85%。避开行人、水面、反光及其他独立运动物体，不以整画面代表车船或扶梯。
- `foreground` 二选一：`{"mask":"foreground.png","space":"screen"}`，或示例中的轮廓关键帧。蒙版按亮度读取，白色保留源画面、黑色无遮挡、灰色部分覆盖，不读取 Alpha；相对路径以场景 JSON 所在目录为准，图片缩放到画面大小。
- 关键帧 `time` 为镜头内秒数，递增；多边形至少三点，各帧顶点数量与顺序相同。线性插值，首尾之外保持最近轮廓；图片只能指定一个关键帧。
- `space=screen` 为屏幕坐标；`space=support` 为随同一承载面运动的首帧轮廓。多处静态遮挡可合并到一张蒙版，交付时保留引用文件。

轨迹不成立时尝试备用位置与缩小尺寸，再整镜头使用顶层贴纸；人工双狗采用一致层级，降级后不应用遮挡蒙版。矛盾设置不能阻止交付：必要时调整落点或放宽禁区，保证至少一只完整小狗并记录原因。按实际轮廓预览和修正，无法修正时说明贴纸降级。
